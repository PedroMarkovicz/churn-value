# 0010 — English, amounts in £

**Context.** The audience includes international recruiters, and the dataset comes from a UK retailer.

**Decision.** The app, README, model card and code are in English. Amounts stay in £, without conversion.

**Alternatives.**
- Bilingual i18n: doubles the cost of all text.
- PT-BR: limits reach.
- Converting amounts to R$: artificial.

**Consequences.** All text is maintained in a single language.
